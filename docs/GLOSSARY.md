# GLOSSARY

Plain-language definitions for readers new to language models. Terms are defined the way they are used in Project XYZ.

## A–D

| Term | Definition |
|---|---|
| **AdamW** | The optimizer used everywhere in this project (parameter update rule with weight decay). |
| **Attention** | The mechanism by which each token looks at other (earlier) tokens to gather context. |
| **BPE** | Byte-Pair Encoding — tokenization by repeatedly merging the most frequent byte/char pairs. |
| **Batch** | A group of sequences processed together (16 in this project). |
| **catA_strict** | Fraction of Cat A answers where the expected keyword appears in the first 8 generated tokens. |
| **Cat A / Cat B** | Benchmark sections: Cat A = semantic correctness categories; Cat B = generation quality. |
| **Catastrophic forgetting** | New training destroying previously learned ability (grammar 55.6→33.3% observed). |
| **Checkpoint** | A saved snapshot of the model (weights + optimizer/scheduler/RNG/config). |
| **Composite** | A weighted index of benchmark scores. NOT a percentage of "understanding". |
| **Context length / window** | How many tokens the model can look at (512). |
| **Cosine schedule** | Learning-rate decay following a cosine curve after warmup. |
| **Cross-entropy** | The loss function measuring how wrong the next-token prediction is. |
| **d_ff** | Feed-forward hidden dimension (1,024). |
| **d_model** | Hidden/embedding dimension (256). |
| **Decoder-only** | An autoregressive architecture that only predicts the next token (no encoder). |
| **Dialog drift** | The model spontaneously emitting `User:`/`Assistant:` markers (bad for Cat B). |

## E–L

| Term | Definition |
|---|---|
| **Echo** | The model just repeating the prompt instead of answering (counted as FAIL). |
| **EOS / BOS** | End-Of-Sequence (id 3) / Beginning-Of-Sequence (id 2) special tokens. |
| **FineWeb** | Public web-text dataset (CC-MAIN-2025-26) used for pretraining and preservation. |
| **Fine-tuning** | Continuing training on task-specific data after pretraining. |
| **GELU** | The activation function used in the feed-forward network. |
| **Generalization** | Performing correctly on unseen inputs (the goal). |
| **Greedy decoding** | Always picking the argmax (highest-probability) token — deterministic. |
| **Gradient** | A vector telling how to adjust parameters to reduce loss. |
| **Head** | One attention channel (8 heads here). |
| **Held-out** | Data never used in training, used for testing. |
| **Instruction data** | Examples teaching the model to follow instructions (Alpaca, synthetic). |
| **Leakage** | When test data accidentally appears in training — invalidates evaluation. |
| **Logits** | Raw per-vocabulary scores before softmax. |
| **Loss** | How wrong predictions are; lower = better training. |
| **Loss masking** | Restricting loss to certain tokens (here: the Assistant answer span). |

## M–R

| Term | Definition |
|---|---|
| **max_new_tokens** | Maximum number of tokens to generate in response. |
| **Memorization** | Storing training strings verbatim instead of learning patterns (bad). |
| **Multi-hop** | Reasoning requiring two+ chained facts. |
| **OOD** | Out-of-distribution — inputs unlike the training distribution. |
| **Overfitting** | Fitting training data so exactly that generalization suffers. |
| **Paraphrase** | Same meaning, different wording (owns/has/possesses). |
| **Pre-LN** | LayerNorm before the attention/FFN sub-block (the ordering used). |
| **Pretraining** | Initial large-scale training on general text. |
| **Procedural data** | Data generated by templates with varied values (names, colors, objects) so no string repeats. |
| **RNG** | Random-number-generator state saved in checkpoints for reproducibility. |
| **Reposition / relation** | A relationship between entities (owned-by, located-at, etc.), possibly directional. |

## S–Z

| Term | Definition |
|---|---|
| **Semantic binding** | Reliably connecting entity → relationship → object/property → answer (the SEMV2E focus). |
| **Semantic data** | Synthetic QA-style examples teaching meaning, not just fluency. |
| **Smoke test** | A tiny (10-step) run to verify the code path works (no network). |
| **Softmax** | Turns logits into a probability distribution. |
| **Step** | One optimizer update on one batch (16 × 512 = 8,192 tokens). |
| **Temperature** | Sampling randomness: 0 = greedy; higher = more random. |
| **Top-k** | Sampling restricted to the k highest-probability tokens. |
| **Token** | A piece of text (word/subword/byte) represented by an integer ID. |
| **Tokenizer** | Converts text ↔ token IDs (16k BPE here). |
| **Transformer** | The neural-network architecture class: attention + feed-forward blocks. |
| **Validation loss** | Loss on a held-out monitor set (FineWeb window) not used for tuning. |
| **Warmup** | A short phase where LR increases linearly to its peak. |
