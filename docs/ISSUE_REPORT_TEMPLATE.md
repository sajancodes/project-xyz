# Issue Report Template

## Summary

A short, specific description of the observed problem.

## Environment

- Git commit SHA:
- Operating system/runtime:
- Python and relevant library versions:
- GPU/device:
- Configuration file:
- Model/checkpoint:
- Dataset version (if applicable):

## Reproduction steps

1. State the exact command or notebook cell.
2. List required setup.
3. Describe the input used, removing private or sensitive content.

## Expected behavior

Describe the documented or intended behavior.

## Actual behavior

Include the observed output, error message, or a small relevant log excerpt.

## Reproducibility

- [ ] Happens every time
- [ ] Intermittent
- [ ] Not reproduced yet

## Artifacts

Link sanitized logs, minimal examples, and relevant checkpoint metadata. Do not attach credentials, access tokens, or private training data.

## Troubleshooting already attempted

List each change and its outcome. Avoid bundling several unrelated changes into one attempt.

A useful issue makes it possible to distinguish a code defect from an environment, data, configuration, or evaluation-protocol problem.
